# الولي للخدمات القانونية

Static Arabic (RTL) landing page. Plain HTML, CSS and JS, no build step.

## Settings
- WhatsApp number, opening hours and time zone: `js/main.js` (`CONFIG`).
- Contact details, services, FAQ and SEO tags: `index.html` (the FAQ text appears twice: once in the page and once in the JSON-LD block, keep them identical).

## Hero photo
Add the lawyer's cut-out portrait as `assets/hero.webp` (transparent background, about 4:5). Until the file exists the page shows the logo watermark instead.

## Domain
Target: https://elwali.aldiwan.io/ (canonical, sitemap and `llms.txt` already use it).
